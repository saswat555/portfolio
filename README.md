## 📦 Getting Started

1. **Clone** this repo  
   ```bash
   git clone https://github.com/saswat555/portfolio.git
   cd portfolio
````

2. **Install** dependencies

   ```bash
   npm install
   ```

3. **Run** in development

   ```bash
   npm start
   ```

   Open [http://localhost:3000](http://localhost:3000).

4. **Build** for production

   ```bash
   npm run build
   ```

5. **Deploy** to GitHub Pages

   ```bash
   npm run deploy
   ```
